FIELD MANUAL

三步部署

适用于 Forge 1.20.1 + TACZ。更新前建议完全退出游戏，避免旧 zip 句柄被占用。

  1. 01

    获取发布包

    下载 GitHub Release 中的 Modern Warfare 4-<版本>.zip。

  2. 02

    放入 TACZ

    把 zip 放进实例的 .minecraft/tacz/ 目录，不要解压。

  3. 03

    重新载入

    启动游戏，或执行 /tacz reload；更新枪包时请重启客户端。
