# Modern Warfare 4 1.8.0-Release

## 新增内容

- 新增 MCX SPEAR LT 突击步枪：5.56x45、30 发、扩容 45/50/60，含 29 段动画、85 条音效与专属状态机。
- MCX SPEAR LT 物品栏图标更换为新图。

## Bug 修复

- **MK23 能装备狙击镜和步枪标准红点**：MK23 的配件白名单里混着 `#tacz:scope_lowsight`，
  它会展开成 27 项步枪/狙击镜（PSO-1、PGO-7、1P68、Kobra、PK06 等），手枪因此能装高倍镜。
  现在白名单只保留手枪红点（`#tacz:pistol_sight`，7 项），MK23 只能装手枪瞄具。
- **MRAD 收枪没有声音**：`put_away` / `put_away_empty` 的 `sound_effects` 是空的（音效文件还在包里，
  只是动画引用被删掉了）。已补回 `drop_rattle`，并把键位放到播放头可闻窗口内（0.0334），收枪恢复有声音。
- **MCX 换弹时备弹匣（addmag）悬在弹匣井里原地打转**：上一版把 `additional_magazine` 的
  position 钉成了常量，抹掉了源动画"从画面下方升上来、插进弹匣井、再落回"的整段运动。
  现已恢复源动画的 position / rotation，六段换弹的备弹匣动作恢复正常。
- **MCX 空仓换弹时备弹匣里没有子弹**：TACZ 的备弹匣是把真实弹匣整棵子树重画一遍，空仓换弹时
  真实弹匣必须是空的，备弹匣因此也跟着空。现在借用模型自带的克隆子弹网格（`bullet_in_mag2`）
  只在备弹匣上显示子弹，插入完成后交回真实弹匣，不会双份重叠。
- **MCX 开火时手臂单独抖动**：旧 `shoot` 片段把手臂各自打了关键帧。已改用重做后的开火动画，
  后坐力由 `root` 与 `camera` 承担，手臂随枪身同步、不再自己乱晃。
- **MCX 持枪/开镜视角偏远、枪身整体偏左**：视点节点沿枪管前移（`idle_view`/`camera` z 7→6、
  `iron_view` z 5→3.5），并把横向偏移回收 0.4 修正左偏；`iron_zoom` 由 1.33 提到 1.5，
  开镜倍率与包内其它 5.56 步枪一致。

## 其他变更

- 仅包含上述 bug 修复与新增内容，没有其它玩法改动。
