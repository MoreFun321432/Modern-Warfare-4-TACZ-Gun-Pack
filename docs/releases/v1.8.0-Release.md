# Modern Warfare 4 1.8.0-Release

## 新增内容

- 新增 MCX SPEAR LT 突击步枪
- MCX SPEAR LT 物品栏图标更换为新图

## Bug 修复

- **MK23 瞄具兼容**：不再能装狙击镜和步枪红点，只保留手枪红点
- **MRAD 收枪音效**：收枪不再静音
- **MCX 备弹匣动作**：换弹时备弹匣不再原地打转，恢复取匣、插入、归位
- **MCX 开火手臂**：开火时手臂不再单独抖动，随枪身同步后坐
- **MCX 持枪视角**：持枪与开镜更近，枪身回到正中

## 其他变更

- 仅包含上述 bug 修复与新增内容，没有其它玩法改动
